# СЭДМ+ — версия 1.0

Небольшой личный дневник С → Э → Д → М для iPhone. Интерфейс на русском, работает в браузере и устанавливается как PWA.

## Что есть в версии 1

- Ситуация → эмоции с интенсивностью 0–100 → действие → мысль (в указанном порядке).
- Необязательные поля «Проверка мысли» и «Альтернативная мысль».
- Дата и время, черновики, автоматическое локальное сохранение после ввода.
- История, редактирование, удаление, поиск, фильтры по эмоции/дате/статусу.
- Полная резервная копия `.json`, восстановление с объединением по ID, экспорт `.csv` для Excel (UTF-8 BOM, разделитель `;`).
- Светлая, тёмная и системная темы, офлайн-кэширование PWA после первого открытия.
- Диктовка текста с помощью микрофона **клавиатуры iPhone**. Отдельных аудиофайлов приложение не записывает.

## Самый простой способ установить на iPhone

Нужен доступный по **HTTPS** адрес. Файлы нельзя просто открыть через приложение «Файлы» и ожидать полноценную PWA.

### Вариант: GitHub Pages (бесплатно)

1. Создай **отдельный репозиторий** на GitHub, например `sedm-plus`. Для бесплатного GitHub Pages обычный вариант — публичный репозиторий. В нём находится только **исходный код**, никаких записей дневника.
2. Загрузи содержимое папки `sedm-plus` в корень репозитория (не сам ZIP и не дополнительную вложенную папку).
3. Открой в репозитории `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch`. Выбери `main` и `/ (root)`, сохрани.
4. После публикации открой на iPhone адрес формата `https://ТВОЙ-ЛОГИН.github.io/sedm-plus/` в **Safari**.
5. Нажми «Поделиться» → «На экран Домой» (или `Add to Home Screen`) → «Добавить». Открой новую иконку «СЭДМ+» с домашнего экрана.
6. Создай тестовую запись, закрой и вновь открой приложение. Проверь историю. Затем экспортируй JSON и сохрани копию в безопасном месте.

Альтернатива: загрузить эти же статические файлы на любой HTTPS-хостинг с поддержкой service worker (например Netlify). Никакого сервера для самих записей не требуется.

## Как использовать

- «+ Новая запись» → заполни поля → «Сохранить» (требуются все четыре основных элемента) или «Сохранить черновик» (достаточно одного поля).
- В текстовом поле открой системную клавиатуру iPhone и нажми её микрофон. Если микрофон не виден, проверь настройки диктовки iOS.
- Черновик с содержимым сохраняется автоматически при изменении полей и переходе между экранами. Никаких пустых записей приложение не создаёт.
- «История» → нажми запись для редактирования.
- «Экспорт» или ⚙ → скачай `.json` (для восстановления) либо `.csv` (для Excel).
- Для восстановления: ⚙ → «Восстановить из копии» → выбери **JSON**, а не CSV. При совпадении ID запись из копии заменит текущую; остальные локальные записи останутся. Для страховки перед восстановлением экспортируй текущую копию.

## Важно о конфиденциальности и сохранности

- Приложение не содержит SDK аналитики, рекламы, серверного API или подключения к AI.
- Записи сохраняются в **IndexedDB** на конкретном устройстве/в конкретном браузерном контексте. Данные могут быть потеряны из-за очистки сайта, смены браузера/устройства, удаления PWA или политики хранения iOS. Автосохранение **не заменяет резервную копию**.
- Не рассчитывай, что данные Safari и установленного приложения обязательно синхронизируются между собой. Основным местом ведения дневника выбери установленное приложение.
- В версии 1 **нет** отдельной блокировки Face ID/кодом и **нет** шифрования записей на уровне приложения. Используй защиту устройства и не предоставляй доступ к разблокированному iPhone.
- CSV и JSON содержат чувствительную информацию **в открытом виде**. Не отправляй их в общедоступные папки. Если хранишь в iCloud Drive/OneDrive, настрой доступ и защиту учётной записи.
- Диктовка клавиатуры обрабатывается средствами iOS/Apple, и в зависимости от условий обработка речи может происходить не исключительно на устройстве. Само приложение не передаёт ни аудио, ни текст внешним AI-сервисам.
- Полное удаление записей из приложения **не удаляет** ранее сделанные экспортированные копии или резервные копии самого устройства.
- Режим офлайн доступен после успешной загрузки ресурсов по HTTPS и установки service worker. Не закрывай первоначальную загрузку до окончания.

## Разработка на компьютере

Запусти HTTP-сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000/` в браузере. `localhost` — безопасный контекст для тестирования PWA на компьютере. Для iPhone нужен публичный HTTPS или собственный корректно настроенный HTTPS.

Файлы: `index.html` (экраны), `styles.css` (дизайн), `app.js` (данные и интерфейс), `sw.js` (офлайн-кэш), `manifest.webmanifest` (установка), `icons/`.

## Известные ограничения

- Нет свободного голосового рассказа с AI-распределением (план версии 2).
- Нет прямой синхронизации Excel/OneDrive, Face ID, PDF-отчётов и статистики (поздние версии).
- Для Excel предусмотрен **CSV**, не нативный `.xlsx`: Excel умеет открывать CSV, но при необходимости может потребоваться выбрать разделитель «точка с запятой».
- Автоматическое тестирование на реальном iPhone ещё требуется; прогон синтаксиса JavaScript не заменяет теста в Safari.

## Проверка после установки

1. Создать запись с двумя эмоциями, выставить разные проценты; сохранить.
2. Открыть историю, изменить мысль, проверить сохранение.
3. Создать черновик и закрыть приложение, снова открыть его из истории.
4. Экспортировать JSON, затем повторно импортировать и проверить, что записи не дублируются.
5. Экспортировать CSV, открыть в Excel, проверить русские символы, несколько эмоций и кавычки в тексте.
6. Включить авиарежим, открыть установленное приложение и проверить доступ к сохранённым данным.
